# Entitlement für Chat-Anfragen

- Chat, Onboarding und proaktive Analysen dürfen nur mit einem gespeicherten
  Sponsoring-Entitlement ausgeführt werden.
- Ohne Token muss der Adapter vor jedem LLM-Aufruf mit einer klaren Meldung
  abbrechen.
- Beta-Versionen sind von dieser Prüfung nicht ausgenommen.
- Ein abgelaufenes Token folgt weiterhin dem bestehenden Grace-/Tageskontingent-
  Verhalten; die Änderung betrifft ausschließlich vollständig fehlende Tokens.
