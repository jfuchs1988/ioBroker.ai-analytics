# 9. Architekturentscheidungen

[← zurück zur Architektur-Übersicht](arc42-index.md)

Getroffene Entscheidungen werden als einzelne Architecture Decision Records (ADRs) im [Nygard-Format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) festgehalten (Kontext, Entscheidung, Konsequenzen) — siehe **[ADR-Übersicht](../adr/adr-index.md)** für die vollständige, laufend nummerierte Liste.

Fragen, die architekturrelevant sind, aber noch **nicht** entschieden wurden, stehen gesammelt im **[Backlog offener Architekturentscheidungen](../adr/backlog.md)** — dort werden sie diskutiert, bevor sie als eigene ADR aufgenommen werden.
